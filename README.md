# ValeOS

Aplicação interna para acompanhar a operação comercial e a entrega de projetos de uma pequena empresa de tecnologia e automação.

O [PRD v1.0](docs/ValeOS_PRD_v1.0.md) é a referência de produto. A implementação é incremental; o estado de cada etapa e as instruções para executar o aplicativo ficam neste README à medida que forem entregues.
